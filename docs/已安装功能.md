## 五、踩过且已修

| 现象 | 根因 | 修法 |
|---|---|---|
| 桥重启后游戏里说话没人理 | 游标 `Math.max` 永不回退 | 序号回落 → 重置为 0 |
| 聊天显示 `<Kan> [Kan] xxx` | 手动前缀 + bot.chat 自带名字 | 去掉手动前缀 |
| 控制文件读不到 | 电脑重启后桥没起 | 手动跑启动脚本 |
| 名字改了进不去 | 白名单 UUID 按大小写算 | 名字一字不差 |
| `come_to_player` 明明走到了却报 failed | 回执只看状态字段，动作已完成 | 未修（不影响使用） |
